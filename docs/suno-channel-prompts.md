# 四個頻道:基底提示詞與變化軸

用法:每首歌的 Style 欄 = `基底` + 從每個變化軸各挑 1 項(用逗號接起來)。
Exclude / Negative 欄(每個頻道都填):`vocals, singing, humming, lyrics, choir, spoken word, rap`
每個頻道有 5 軸,各軸 5~6 個選項,可組出數百種不同組合;20 首只要確保「任兩首至少 2 個軸不同」即可。

## 提醒

- 如果你的 Suno 版本 Style 欄字數有限(舊版約 200 字元),把基底縮短成前半段,只保留曲風 + 2~3 個樂器 + 變化軸。
- 同一頻道內,**一次生成 2 首只挑 1 首**,並確保任兩首至少有 2 個軸不同,避免曲庫變成同一首的翻版。
- 這些提示詞是依常見寫法整理,還沒實際在 Suno 驗證;生成前 3 到 5 首後如果風格偏掉,微調基底即可。
